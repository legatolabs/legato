# About the lab

Legato Labs works on the loop between a model and the machine it operates: screenshot, decide, act, wait for the screen. We publish what we measure, same model and same desktops, with the bars set before each run.

# Legato Cloud

The open-source harness runs on any computer. Legato Cloud runs the model and the desktop side by side, so it saves time the loop alone cannot. Each number is one part, measured; method and raw data.

2.3–2.7×
faster prefill per step: each run's history stays cached on one engine, and the next request is prefilled while the screen settles
1.27×
faster median task with speculative decoding on the hosted open model
2.0 s
to fork a running desktop through the API, open apps and memory included
warm pool
desktops boot ahead of time, so a run rarely waits for one

In development

0.7–0.9 s
to restore a desktop from a memory snapshot, vs 3.9–7.4 s to boot one and replay to the same point
no re-prefill
when a whole run forks: the fork keeps the model's cached history
16×
denser: 16 desktops per container, 15.6× less container time per episode

# Start
# pip install "legatolabs[e2b]"
import os, legato
from e2b_desktop import Sandbox

agent = legato.Harness(model="qwen/qwen3.8-27b",
                       base_url="https://openrouter.ai/api/v1",
                       api_key=os.environ["OPENROUTER_API_KEY"])
desk = Sandbox.create()     # or legato.local(), or legato.attach(shell=run) for your sandbox
result = agent.run("Open the terminal and print the date", legato.attach(desk))
print(result.report())   # model, actions, waiting for the screen
# a computer for Claude Code, Cursor or any MCP client
pip install "legatolabs[mcp,local]"
claude mcp add legato -- legato mcp --sandbox docker         # a desktop container
claude mcp add legato -- legato mcp --local                  # your screen
claude mcp add legato -- legato mcp --sandbox my.py:desktop  # your sandbox

# or the Claude Code plugin (server + skills)
/plugin install legato --marketplace legatolabs/legato
