Computer use for any model, without the waiting.

Legato is an open-source computer-use harness for any OpenAI-compatible model: Qwen, DeepSeek, Claude, or your own vLLM server. It drives a desktop with a Claude-style computer tool, waits until the screen is ready instead of sleeping a fixed time, and bounds every model call.

How it works

Every step of the loop, tuned

A computer-use agent spends its time in the loop between the model and the machine, hundreds of times per task. Legato shortens the parts the model provider and the sandbox provider each leave alone.

01

Screenshot

Capture the screen.

Taken once the screen has settled. On E2B, the check runs inside the sandbox in a single call.

02

Read history

The model reads the task and recent screens.

Old screenshots are dropped in chunks, so the provider's prompt cache keeps hitting.

03

Write action

A click, keystroke or text.

Any model, up to 3 actions per turn, short replies, and a token budget and wall-clock timeout on every call.

04

Act

Send the action to the desktop.

One remote call per action on E2B. Any other sandbox plugs in through two functions.

05

Settle

The screen finishes updating.

Waits exactly as long as the screen needs, never longer than the 2 s sleep it replaces.

Quickstart

Three ways in

Run the harness with your own model key, give your coding agent a desktop through MCP, or use the command line.

# pip install "legato[e2b]"
import os, legato
from e2b_desktop import Sandbox

agent = legato.Harness(model="qwen/qwen3.8-27b", base_url="https://openrouter.ai/api/v1",
                       api_key=os.environ["OPENROUTER_API_KEY"])
desk = Sandbox.create()
result = agent.run("Open the terminal and print the date", legato.attach(desk))
print(result.report())   # where the time went: model, actions, waiting for the screen
desk.kill()
# a cloud desktop for Claude Code, Cursor or any MCP client
pip install "legato[e2b,mcp]"
claude mcp add legato -e E2B_API_KEY=your_key -- legato mcp

# every action returns once the screen has settled, with the new screenshot
pip install "legato[e2b]"
export OPENROUTER_API_KEY=... E2B_API_KEY=...
legato run "Create a folder named reports on the desktop" \
    --model anthropic/claude-sonnet-5.5 --base-url https://openrouter.ai/api/v1
Managed · beta

Desktops and models, run for you

The managed service runs the desktops and the model for you. Desktops pause, resume and fork with their memory intact. Open models are served with warm sessions, and graded RL rollouts run at scale. The open-source harness never requires it.

API keys are issued by hand during the beta. Questions: hello@legato.computer
