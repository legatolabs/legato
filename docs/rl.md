# RL rollouts

RL rollouts at scale are part of **Legato Cloud**, in beta. An agent learns computer work by trying tasks over and
over, and every attempt runs on a real machine, so the attempts you can run per hour set the price of training.
Legato Cloud runs the model and the desktop side by side and forks both together, so rollouts branch mid-task instead
of starting over.

Join the waitlist on [legato.computer](https://legato.computer), or write to us if you're training agents that act.

The open-source runtime is the same loop on your own machine: [Terminal and Python](python.md),
[desktops](sandboxes.md), [benchmarks](benchmarks.md).
